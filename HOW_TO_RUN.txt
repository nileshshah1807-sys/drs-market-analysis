============================================================
DR. NILESH SHAH'S MARKET ANALYSIS
How to Run Guide
============================================================

EASIEST: Double-click "DR Nilesh Shah Market Analysis.exe" in this folder.
          (No Python needed. Keep it next to the "_internal" folder.)
          To rebuild it after changing the code: double-click build_exe.bat

The steps below are only needed to run from the Python source code.


STEP 1: INSTALL ALL DEPENDENCIES
---------------------------------

Option A: Double-click "install_dependencies.bat" (Windows)
   This will automatically install all required packages.

Option B: Open Command Prompt and run:
   python -m pip install -r requirements.txt


STEP 2: VERIFY INSTALLATION
-----------------------------

Run this command to verify:
   python -c "import yfinance, pandas, numpy, ta, openpyxl, reportlab, pdfplumber; print('All OK!')"


STEP 3: RUN THE APP
---------------------

Option A: Double-click "run_app.bat"
Option B: Run: python dr_shah_analysis.py


NEW FEATURES
--------------

1. BACKTEST tab
   Click "Run Backtest" to see whether the score actually predicted returns
   for your watchlist over the past 2-5 years, which indicators help or hurt,
   and suggested weights (learned on older data, checked on newer data).
   "Apply Suggested Weights" saves them; Settings > "Reset Defaults" undoes it.

2. FAST SCANS
   All stocks download in one batch and prices are cached in the
   "data_cache" folder, so re-scans only fetch the latest days.
   (Safe to delete data_cache - it is rebuilt automatically.)

3. EMAIL REPORT WITHOUT THE APP OPEN
   Settings > Auto Report Scheduling > set the time > "Install Windows Task".
   The report is emailed on NSE trading days (weekends and NSE holidays are
   skipped, never sent twice a day). The PC must be on and you must be
   logged in. "Remove Windows Task" turns it off.
   Test it manually:  python scheduled_report.py --force

4. LIQUIDITY FLAG
   Scan Results has a "Traded/day (Cr)" column. Stocks below the threshold
   (Settings > Liquidity Filter, default Rs 1 crore/day) are marked LOW,
   get a warning on the Stop-Loss & Targets tab, and can be hidden with
   "Hide illiquid". The Backtest tab can test liquid stocks only.

5. MORE ACCURATE SIGNALS
   - Newly listed stocks are no longer scored as bearish just because they
     don't have 200 days of history yet (missing averages are skipped).
   - Chart patterns must be recent (last ~3 months) and can no longer show
     bullish and bearish reversals at the same time.
   - Dividends shown as "Expected ... (ESTIMATED - not announced)" are
     projections from past years, not announcements.

6. EMAIL PASSWORD STORED SAFELY
   The Gmail App Password is kept in Windows Credential Manager
   (Control Panel > Credential Manager > Windows Credentials >
   "DR Nilesh Shah Market Analysis - Email"), not in email_config.json.
   To change it, enter the new one in Settings and click "Save Email Config".
   "Clear Config" removes it from Credential Manager too.


7. VS NIFTY, SCORE CHANGES AND HISTORY
   Scan Results shows "vs Nifty 3M" (the stock's 3-month return minus the
   Nifty 50's) and "Score Chg" (change since your previous scan day).
   After each scan the app lists stocks whose signal changed; the watchlist
   email includes them too. Score Breakdown shows a score-history chart.
   Every scan is saved in score_history.csv (opens in Excel).

8. SCORING WEIGHTS RE-CHECK
   Weights applied from the Backtest tab are re-checked against the default
   weights every 30 days (or click "Re-check Weights"). If the defaults do
   better on recent data, the app tells you. Settings > Reset Defaults
   restores the original weights.

9. ONE COPY AT A TIME
   Opening the app while it's already running brings the open window to the
   front, so two copies can't overwrite each other's watchlist and settings.

10. FULL AUTOMATIC TEST
   Double-click run_tests.bat - tests every feature on a throwaway copy.

11. NEW LISTINGS ARE SCANNED ON 1-HOUR CANDLES
   A stock listed less than a month ago doesn't have enough daily candles,
   so the scan uses its 1-hour candles for every indicator (RSI, MACD,
   averages, SuperTrend, VWAP, ATR, patterns ...). Scan Results marks it
   "1 Hour" in the "Candle" column; reports mark it with a *.
   - It gets a score from its 3rd trading day (20 hourly candles). Before
     that the scan lists it as "listed under 3 trading days ago".
   - Its stop-loss and targets come from hourly price swings, so they sit
     closer to the price than for stocks analysed on daily candles.
   - "vs Nifty" shows N/A until it has traded for the full period.
   - After a month it switches to daily candles like every other stock, so
     its score can jump that day.

12. FIXES FROM THE OCTOBER 2026 DEEP SCAN
   - The daily emailed report now gives every stock the SAME score and
     signal as the scan (it used a simpler formula of its own: 3 stocks
     in 4 showed a different signal). Scores in the report change once.
   - The report's Top Picks no longer list a stock twice (NSE and BSE),
     its "Nifty 50" is NSE's current list, and its news is real headlines
     (it was showing made-up placeholder lines when Yahoo had no news).
   - SuperTrend now flips on the same candle as broker charts (standard
     ATR smoothing); about 1 stock in 20 shows a different SuperTrend.
   - 1-month chart no longer says "No data" in months with few trading days.
   - Corporate Actions: an event announced on both NSE and BSE is listed
     once; "Amount" is shown for dividends only.
   - Import: files saved by Excel no longer lose their first symbol, and
     a heading such as "Symbol" is no longer added as a stock.
   - Report PDFs shrink from about 2 MB to under 100 KB (the logo was
     stored full-size in each one).

13. STOP-LOSS AND TARGETS FROM SUPPORT AND RESISTANCE
   The stop-loss now sits just beyond the stock's nearest support (for a
   SELL: its nearest resistance) and the three targets at its next
   resistance levels (for a SELL: supports). The levels are the swing
   highs and lows of the last year. The Stop-Loss & Targets tab says where
   each level comes from, e.g. "Just below support at 96.00, tested 3
   times".
   - Risk:Reward now differs from stock to stock: low when a resistance is
     close overhead, high when the next one is far. Before, every BUY
     showed 1:1.67 because all levels were fixed multiples of the ATR.
   - Where a stock has no level within reach (for example at a new high,
     with no resistance above), a multiple of its ATR is still used and
     the tab says so.
   - The daily emailed report uses the same levels.

14. SECTOR ROTATION SHOWS DIRECTION, NOT JUST STRENGTH
   The Sector tab has a "Chg" column: the change in each sector's average
   score since the scan of about a week earlier (or your previous scan
   day, until the score history is a week long). Rotation is now:
     LEADING    above your watchlist's average and not falling
     WEAKENING  above average, but the score has fallen
     IMPROVING  below average, but the score has risen
     LAGGING    below average and not rising
   Before, "IMPROVING" and "WEAKENING" only reflected the score level.

15. MARKET OPEN / CLOSED LIGHT KNOWS NSE HOLIDAYS
   On an NSE holiday the light shows "Market closed: NSE holiday". The
   holiday list is downloaded again every week, so holidays declared
   during the year are picked up (also by the scheduled email report).

16. UNUSED FILES REMOVED
   ai_engine.py and live_trading.py were never used by the app and have
   been deleted; scikit-learn is no longer installed for the app.

17. NEW LOOK: DAYLIGHT DESIGN, DARK MODE, 3D AND ANIMATIONS
   - Light "Daylight" design. Settings > Appearance > Dark switches to dark
     mode straight away (your results stay on screen) and is remembered.
   - Settings > Appearance > Animations turns the motion on or off.
   - Raised 3D buttons that press down, a sliding tab underline, a scan
     summary that counts up, a score ring that sweeps round, bars that
     grow, price charts that draw themselves in, and a pulsing market light.
   - After a scan, the result slides in at the bottom right instead of a
     box you had to close; rows whose signal changed glow for a moment.
   - Charts tab > "3D market map": every scanned stock in 3D (score, RSI,
     strength vs the Nifty 50). It turns by itself; click it to stop and
     drag to turn it.
   - Sector tab: a 3D chart of buy, hold and sell stocks in each sector.

18. ADD A STOCK BY THE COMPANY'S NAME
   In the "Add a stock" box, type the first three or four letters of the
   company's name. A list drops down showing each matching company's full
   name with its NSE symbol and its BSE symbol and code. Pick one with the
   arrow keys and Enter, or click it. Typing a symbol or a BSE code works
   too. The list has every NSE (main board and SME) and BSE company and is
   refreshed from the exchanges every week; a stock listed in the last few
   days can still be added by typing its symbol.
   The watchlist now shows each company's name beside its symbol.


TROUBLESHOOTING
-----------------

Problem: "No module named 'ta'"
Fix: python -m pip install ta

Problem: "No module named 'yfinance'"  
Fix: python -m pip install yfinance

Problem: "Daily report module not found"
Fix: Make sure daily_report.py is in the same folder as dr_shah_analysis.py

Problem: "No module named 'reportlab'"
Fix: python -m pip install reportlab

Problem: App doesn't start
Fix: Run install_dependencies.bat first
