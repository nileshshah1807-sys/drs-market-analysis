DR. NILESH SHAH'S MARKET ANALYSIS
How to Run Guide
============================================================

STEP 1: INSTALL ALL DEPENDENCIES
---------------------------------

Option A: Double-click "install_dependencies.bat" (Windows)
   This will automatically install all required packages.

Option B: Open Command Prompt and run:
   python -m pip install -r requirements.txt


STEP 2: VERIFY INSTALLATION
-----------------------------

Run this command to verify:
   python -c "import yfinance, pandas, numpy, ta, sklearn, openpyxl, reportlab, pdfplumber; print('All OK!')"


STEP 3: RUN THE APP
---------------------

Option A: Double-click "run_app.bat"
Option B: Run: python dr_shah_analysis.py


NEW FEATURES
--------------

1. BACKTEST tab
   Click "Run Backtest" to see whether the score actually predicted returns
   for your watchlist over the past 2-5 years, which indicators help or hurt,
   and suggested weights (learned on older data, checked on newer data).
   "Apply Suggested Weights" saves them; Settings > "Reset Defaults" undoes it.

2. FAST SCANS
   All stocks download in one batch and prices are cached in the
   "data_cache" folder, so re-scans only fetch the latest days.
   (Safe to delete data_cache - it is rebuilt automatically.)

3. EMAIL REPORT WITHOUT THE APP OPEN
   Settings > Auto Report Scheduling > set the time > "Install Windows Task".
   The report is emailed on NSE trading days (weekends and NSE holidays are
   skipped, never sent twice a day). The PC must be on and you must be
   logged in. "Remove Windows Task" turns it off.
   Test it manually:  python scheduled_report.py --force

4. LIQUIDITY FLAG
   Scan Results has a "Traded/day (Cr)" column. Stocks below the threshold
   (Settings > Liquidity Filter, default Rs 1 crore/day) are marked LOW,
   get a warning on the Stop-Loss & Targets tab, and can be hidden with
   "Hide illiquid". The Backtest tab can test liquid stocks only.

5. MORE ACCURATE SIGNALS
   - Newly listed stocks are no longer scored as bearish just because they
     don't have 200 days of history yet (missing averages are skipped).
   - Chart patterns must be recent (last ~3 months) and can no longer show
     bullish and bearish reversals at the same time.
   - Dividends shown as "Expected ... (ESTIMATED - not announced)" are
     projections from past years, not announcements.

6. EMAIL PASSWORD STORED SAFELY
   The Gmail App Password is kept in Windows Credential Manager
   (Control Panel > Credential Manager > Windows Credentials >
   "DR Nilesh Shah Market Analysis - Email"), not in email_config.json.
   To change it, enter the new one in Settings and click "Save Email Config".
   "Clear Config" removes it from Credential Manager too.


TROUBLESHOOTING
-----------------

Problem: "No module named 'ta'"
Fix: python -m pip install ta

Problem: "No module named 'yfinance'"  
Fix: python -m pip install yfinance

Problem: "Daily report module not found"
Fix: Make sure daily_report.py is in the same folder as dr_shah_analysis.py

Problem: "No module named 'reportlab'"
Fix: python -m pip install reportlab

Problem: App doesn't start
Fix: Run install_dependencies.bat first
